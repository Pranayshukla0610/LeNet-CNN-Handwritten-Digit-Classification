# LeNet-CNN-Handwritten-Digit-Classification
## Overview
This repository demonstrates the implementation of **LeNet-5**, one of the earliest and most influential Convolutional Neural Network (CNN) architectures developed by Yann LeCun. The project focuses on image classification using convolutional layers, pooling operations, and fully connected neural networks.

## Objectives
- Understand the architecture of LeNet-5.
- Implement a Convolutional Neural Network for image classification.
- Learn feature extraction using convolution and pooling layers.
- Evaluate model performance on image datasets.

## Model Architecture

### LeNet-5
The LeNet architecture consists of:

- Input Layer
- Convolutional Layers
- Average Pooling Layers
- Fully Connected Layers
- Output Layer

The network automatically learns hierarchical image features for accurate classification.
